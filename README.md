# Exploratory Data Analysis (EDA)

This project was completed as part of the DecodeLabs Internship Program.

## Project Overview

The goal of this project was to analyze a dataset to understand patterns, trends, and distributions using descriptive statistics and exploratory analysis.

## What I Did

- Calculated basic statistics including mean, median, and count.
- Identified trends and patterns in the dataset.
- Assessed outliers and unusual values.
- Summarized the main findings using analytical reasoning.
- Documented the key observations and business meaning of the results.

## Tools Used

- Microsoft Excel
- Data analysis formulas and summaries
- Excel charting and analysis features

## Project Deliverables

- `project-2-dataset.xlsx` — dataset used for the exploratory analysis
- `project-2-eda-report.pdf` — written report summarizing the findings
- `proof-of-work/` — screenshots showing the analysis, outlier checks, and mean/median calculations

## How to Review

1. Open the workbook and review the dataset and analysis tabs.
2. Check the mean, median, and count calculations.
3. Review the trend and outlier analysis.
4. Read the PDF report for the summary of findings and conclusions.

## Result

The dataset was analyzed successfully, with the key trends, outliers, and descriptive statistics documented clearly.
